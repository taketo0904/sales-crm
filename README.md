# 営業CRM

Salesforce風のミニマム営業管理CRMです。ブラウザだけで商談、リード、取引先、請求、入金確認を管理できます。

## できること

- 商談の追加、編集、削除
- 顧客、担当者、ステージ、入金状態での検索・絞り込み
- パイプライン表示
- 受注後の請求日、入金予定日、入金確認日の管理
- 「入金確認」ボタンで入金済みへ更新
- JSONでのデータ出力・取込
- GitHub Pagesでの公開

## 使い方

`index.html` をブラウザで開きます。実体は `営業CRM.html` です。

入力データはブラウザの `localStorage` に保存されます。サーバーやデータベースは不要です。

## GitHub Pagesで公開する

1. このフォルダをGitHubリポジトリに入れます。
2. GitHubの `Settings` から `Pages` を開きます。
3. `Deploy from a branch` を選び、公開したいブランチを指定します。
4. 発行されたURLにアクセスします。

## 更新方法

アプリ本体を更新するときは `営業CRM.html` を編集します。GitHub Pagesで公開している場合、変更をpushすると公開版も更新されます。

更新前には画面上部の `データ出力` でJSONバックアップを保存してください。更新後に必要であれば `データ取込` で戻せます。

## 誰でも作れるようにする方法

GitHubで公開したあと、利用者はリポジトリをForkするか、テンプレートリポジトリとして複製できます。複製後は `営業CRM.html` の文言、色、サンプルデータを変更すれば、自社用CRMとして使えます。

## ファイル構成

- `index.html`: GitHub Pages用の入口
- `営業CRM.html`: アプリ本体
- `README.md`: 公開・更新手順
